# AI Stock Research Platform

An open-source, India-first stock research platform for live market analysis, technical indicators, pattern detection, AI scoring, alerts, paper trading, backtesting, and portfolio intelligence.

## Main principles
- No real broker execution
- Research-first, not trade-execution-first
- Explainable outputs
- India-first market logic
- Modular, scalable architecture
- Built in phases with checkpoints

## Core features
- Live charts
- Indicators
- Candlestick and chart patterns
- Support/resistance analysis
- Alerts and scanners
- Paper trading
- Backtesting
- AI buy/hold/sell scoring
- Portfolio analytics
- Market regime detection
- Historical prediction archive

## Project memory
The current source of truth is stored in:
- PROJECT_STATE.json
- PROJECT_CHECKPOINT.md
- AI_MEMORY.md
- DECISION_LOG.md
- ROADMAP.md

## Resume rule
If the project pauses, continue from the latest checkpoint instead of restarting.
